# Unidad 1 · Arquitectura del computador y programación en ensamblador

## Archivo 1: Arquitectura del computador Hack

### Propósito
Introducir la arquitectura básica de un computador digital usando el modelo Hack como caso de estudio para establecer una base común antes de programar en ensamblador.

### Sesiones cubiertas
- Sesión 1. Arquitectura básica del computador: CPU, memoria, buses, ROM/RAM y entrada/salida.
- Sesión 2. Modelo Hack y ciclo fetch-decode-execute con simulación guiada.

### Resultados de aprendizaje
- Distinguir los roles de CPU, memoria, buses y periféricos.
- Explicar la diferencia entre ROM, RAM y registros.
- Describir el ciclo fetch-decode-execute sobre un programa simple.
- Usar el simulador Hack para observar el estado interno del sistema.

## Sesión 1. Arquitectura básica del computador

### Objetivo
Reconocer cómo se coordinan los componentes esenciales de un computador para ejecutar instrucciones y procesar datos.

### Temas centrales
- CPU como unidad de control y cálculo.
- Memoria de instrucciones y memoria de datos.
- Buses de direcciones y de datos.
- Relación entre ROM, RAM, pantalla y teclado.
- Diferencia entre hardware visible y modelo abstracto de ejecución.

### Actividades sugeridas
- Lectura guiada del diagrama general del computador Hack.
- Identificación de componentes en una arquitectura simplificada.
- Comparación entre memoria de programa y memoria de trabajo.
- Discusión breve sobre cómo entra una tecla al sistema y cómo sale un pixel a pantalla.

### Evidencias
- Mapa conceptual del computador Hack.
- Respuestas cortas sobre flujo de datos e instrucciones.

## Sesión 2. Modelo Hack y ciclo fetch-decode-execute

### Objetivo
Comprender cómo una CPU ejecuta un programa paso a paso a través del ciclo fetch-decode-execute.

### Temas centrales
- Contador de programa (PC).
- Búsqueda de la instrucción en ROM.
- Decodificación de instrucciones A y C.
- Ejecución y actualización de registros y memoria.
- Observación de cambios de estado en simulación.

### Actividades sugeridas
- Cargar un programa mínimo en el simulador de CPU Hack.
- Predecir el efecto de cada instrucción antes de ejecutarla.
- Registrar cambios en PC, A, D y memoria.
- Explicar por qué un ciclo infinito detiene el avance del programa útil.

### Evidencias
- Tabla de ejecución paso a paso.
- Explicación escrita del ciclo fetch-decode-execute en un ejemplo concreto.

## Recursos sugeridos
- Sitio oficial de Nand2Tetris.
- Simulador web de CPU Hack.
- Documentación del computador Hack.
