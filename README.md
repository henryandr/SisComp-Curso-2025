## Enfoque del rediseño

- Se fusionan las 8 unidades originales en 4 bloques conceptuales más amplios.
- Se priorizan fundamentos de arquitectura, memoria, objetos, estructuras de datos, GPU, OpenGL, concurrencia y paralelismo.
- Las actividades creativas se conservan como laboratorios integradores.
- Las bitácoras, autoevaluaciones y coevaluaciones se condensan dentro de menos sesiones.
