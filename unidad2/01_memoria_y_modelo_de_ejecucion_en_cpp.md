# Unidad 2 · Memoria, objetos y estructuras de datos en C++

## Archivo 1: Memoria y modelo de ejecución en C++

### Propósito
Introducir el entorno de trabajo en C++ y construir un modelo mental claro sobre cómo se ejecuta un programa y cómo se distribuye su memoria.

### Sesiones cubiertas
- Sesión 1. Entorno C++, depuración, funciones y paso por valor, referencia y puntero.
- Sesión 2. Mapa de memoria de un programa: stack, heap, datos, texto y variables estáticas.

### Resultados de aprendizaje
- Compilar, ejecutar y depurar programas básicos en C++.
- Diferenciar paso por valor, referencia y puntero.
- Explicar el mapa de memoria de un proceso.
- Relacionar tipo de almacenamiento con tiempo de vida y acceso.

## Sesión 1. Entorno, funciones y formas de paso

### Objetivo
Usar C++ como laboratorio para observar cómo cambian los datos según la manera en que se pasan a una función.

### Temas centrales
- Flujo básico de compilación y ejecución.
- Breakpoints y ejecución paso a paso.
- Funciones con parámetros por valor, referencia y puntero.
- Efecto observable sobre variables originales.

### Actividades sugeridas
- Ejecutar un programa simple con depurador.
- Comparar el resultado de tres funciones que modifican un entero.
- Registrar qué cambia y qué permanece igual en cada llamada.

### Evidencias
- Captura o tabla de depuración.
- Explicación breve de cuándo usar cada forma de paso.

## Sesión 2. Mapa de memoria de un programa

### Objetivo
Visualizar la memoria de un programa como segmentos con propósitos distintos.

### Temas centrales
- Segmento de código o texto.
- Segmento de datos y variables globales/estáticas.
- Stack y activaciones de funciones.
- Heap y memoria dinámica.
- Relación entre direcciones y ciclo de vida.

### Actividades sugeridas
- Dibujar el mapa de memoria de un programa pequeño.
- Clasificar variables según el segmento donde viven.
- Observar direcciones y tiempos de vida en ejecución.

### Evidencias
- Esquema del mapa de memoria.
- Respuestas justificadas sobre ubicación y duración de variables.
