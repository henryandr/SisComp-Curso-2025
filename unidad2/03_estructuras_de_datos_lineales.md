# Unidad 2 · Memoria, objetos y estructuras de datos en C++

## Archivo 3: Estructuras de datos lineales

### Propósito
Introducir estructuras dinámicas lineales como una aplicación natural de punteros, nodos y memoria dinámica.

### Sesiones cubiertas
- Sesión 6. Listas enlazadas: uso conceptual e implementación manual.
- Sesión 7. Colas FIFO y aplicación interactiva con estructuras de datos dinámicas.

### Resultados de aprendizaje
- Explicar la organización de una lista enlazada.
- Implementar operaciones básicas sobre nodos.
- Distinguir comportamiento LIFO y FIFO a nivel conceptual.
- Aplicar estructuras dinámicas a un problema interactivo.

## Sesión 6. Listas enlazadas

### Objetivo
Comprender cómo una estructura enlazada usa nodos y punteros para crecer dinámicamente en memoria.

### Temas centrales
- Nodo, dato y referencia al siguiente elemento.
- Recorrido secuencial.
- Inserción al inicio o al final.
- Eliminación y actualización de enlaces.

### Actividades sugeridas
- Dibujar una lista enlazada antes de programarla.
- Implementar `push_back`, `pop_back` y `clear`.
- Explicar qué cambia en memoria en cada operación.

### Evidencias
- Implementación manual o pseudocódigo detallado.
- Diagrama del estado de la lista tras varias operaciones.

## Sesión 7. Colas FIFO y aplicación interactiva

### Objetivo
Aplicar una estructura de datos lineal a una experiencia visual o interactiva para reforzar su utilidad práctica.

### Temas centrales
- Política FIFO.
- Encolar y desencolar.
- Estado dinámico ligado a entradas del usuario.
- Visualización de nodos o elementos activos.

### Actividades sugeridas
- Construir una aplicación que agregue y retire elementos visualmente.
- Comparar lista enlazada y cola según la operación dominante.
- Justificar la estructura elegida para el comportamiento buscado.

### Evidencias
- Demostración de la aplicación.
- Explicación del flujo de datos y las operaciones sobre la estructura.
